# .github

 copilot/add-community-health-files
This repository contains organization-level default community health files for the DevNextX organization. These files are used as defaults across all repositories in the organization unless overridden by repository-specific files.

## Community Health Files

This repository includes the following community health files:

| File | Description |
|------|-------------|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant Code of Conduct - defines standards for community engagement |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Guidelines for contributing to our projects |
| [SECURITY.md](SECURITY.md) | Security policy and instructions for reporting vulnerabilities |
| [SUPPORT.md](SUPPORT.md) | Information on how to get help with our projects |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Default template for pull requests |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Issue templates for bug reports and feature requests |

## How It Works

When you create a new repository in the DevNextX organization, these files will automatically be used as defaults if the repository doesn't have its own versions. For more information, see [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Customization

Individual repositories can override these defaults by creating their own community health files in their repository root, `.github` folder, or `docs` folder.

This repo is a template repo which saves the issue/bug template for the repos within this organization.

In the repository, will create one of the supported community health files. Issue templates and their configuration file must be in a folder called .github/ISSUE_TEMPLATE. All other supported files may be in the root of the repository, the .github folder, or the docs folder. For more information, see Creating new files.
